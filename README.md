# Login-and-Registration-System
User Registration: Allows users to create a new account with a username and password. The system verifies that the username doesn't already exist and that the password confirmation matches.
User Login: Authenticates users by checking their credentials against stored information.
Database Management: Creates a "database" directory to store user information in individual text files.
Password Security: Masks password input with asterisks and handles backspace for better user experience.
